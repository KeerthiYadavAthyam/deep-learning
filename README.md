# House Loan Data Analysis
-------------------------
1. I have developed house loan data analysis model by importing loan_data dataset and then found out percentage of default payers. 
2. As the percentage of default payers is very less(around 8%) I have balanced the data by taking a sample of data from paid customers which reduces the bias towards paid customer data. 
3.Identified whether the customer paid loan based on different factors like no of children, gender ,if he has a car etc
4.Encoded the categorical values
5.Created the training and test data.
6.Used Support Vector Machine algorithm for classification.
7.Identified the data as linearly separable by plotting using scatter plot.
8.Calculated the precision, recall and f1 score.
9.Calculated the area under ROC curve
